## 便宜 VPS 的钱到底省在哪

年付几十块、月付十几块的机器，成本一定从某个地方扣掉了。四个地方最常见：

**配置数字好看，跑起来全靠邻居。** 4 核 8G 却卖得比 1 核 1G 还便宜，多半是宿主机上塞了太多虚拟机，高峰期 CPU 抢不到、磁盘 I/O 打满。验证方法很直接：看商家有没有公开 CPU 型号。写了具体型号（比如 EPYC 系列）的，至少知道自己买的是什么；只写“高性能处理器”的，通常在回避。

**年付特价是用来抢现金流的。** 小商家一次性收一年的钱，成本撑不住就关机器。判断标准是运营年限和有没有可查的历史记录，不是页面写得多漂亮。

**“不限流量”背后通常是端口限速。** 流量不计量，速度限在 10Mbps 甚至更低，跑什么都慢。JustHost 这里的写法是“300Mbps 公平共享”，并在括号里折算成每月 93TB+。这个表述比“不限流量”四个字诚实，因为“公平共享”意味着高峰期你的实际速度会被邻居影响。它家的带宽加价也说明了带宽的稀缺程度：+10Mbps 收 ¥16.80/月，独享 1Gbps 要 ¥2240.85/月。

**线路决定国内访问体验，带宽数字决定不了。** 同样是 1Gbps 端口，普通国际线路晚高峰丢包、延迟 200ms 以上是常态，CN2、AS9929、AS4837 这类大陆优化线路才有明显区别。JustHost 的品牌页提到提供面向中国大陆优化的 CN2 连接，但具体某个机房走什么路由，会随节点和时段变。**下单后先别传业务数据，用新机器实测一轮延迟和丢包再决定。**

市面上“超低价 VPS 年付月均 ¥16–¥50 是合理区间”这类说法流传很广，但它是某家商家推广文里的自述口径，不是行业统计。同期可核验的另一头是 RackNerd 的 $21.99/年，折合约 ¥13/月。两个数字都真实存在，只是统计方式不同，别把它们当成同一个结论。

## 年付前要算的三笔账

**第一笔：折扣是一次性的还是循环的。**

海外商家常见的坑是首年低价、续费跳回原价。JustHost 官网当前直接把 -20% 标在价格上，第三方测评把折扣码 PROMO20 描述为“循环 8 折”，也就是续费同样按折后价走。这个说法合理，但账单才是最终依据。下单时看一眼订单页写的是首期价还是循环价，比事后核对省事。

**第二笔：IPv4 是不是单独收费。**

这一条最容易被忽略。官网把 IPv4 地址列在付费附加服务里，¥22.29/月；IPv6 是免费送的，页面还专门写了“适合低成本虚拟服务器，无需购买 IPv4 地址”。如果你的购物车里 IPv4 是单独一行，Sirius 的真实月成本就是 ¥26.10 + ¥22.29 = **¥48.39**，全年约 ¥580.68，接近标价的两倍。

**第三笔：机房是不是你想要的那个。**

41 个国家、80 个机房听起来很宽，但下单流程是先选城市，具体数据中心由系统分配，开通后才在服务页面看到实际位置。官网自己也建议对网络质量敏感的项目先在空机上测一轮。香港、日本、新加坡、美国这几个常见落地点的实际路由差别不小，同一个套餐换个城市，晚高峰体验可能完全不同。

这三笔账算完，你才知道自己买的是 ¥26.10 的机器还是 ¥48.39 的机器。

## 常见问题

**超低价 VPS 能拿来建站吗？**
个人博客、作品集、小流量企业站可以。日 PV 上千、有数据库高频读写、或者跑电商的，1 核 1G 会吃力，至少上到 2GB 内存档。真要做站，先把备份方案想好，JustHost 不提供自动备份。

**年付了商家跑路怎么办？**
没有办法追回。降低风险的做法只有两个：优先选运营年限长的（JustHost 官网自述 21 年，第三方资料追溯到 2006 年）；不要把重要数据只放在一台年付机器上，异地备份比任何商家的承诺都可靠。

**“不限流量”是真的不限吗？**
流量不计量是真的，速度有上限也是真的。JustHost 标的是 300Mbps 公平共享，含义是端口上限 300Mbps、且与同宿主机邻居共享。跑满一个月理论上有 90TB 以上，实际取决于邻居占用了多少。真正在乎带宽稳定的场景，得看它家独享带宽的报价。

**需要备案吗？**
JustHost 的机房分布在海外 41 个国家，不涉及中国大陆的 ICP 备案流程。这一点和阿里云、腾讯云的国内机房不同，后者国内节点建站必须备案。

**现在买还是等黑五？**
官网当前的价格页已经把 -20% 直接标出来了，页面上没有活动倒计时。年付金额一次付清，看到的价格就是现在的价格。真要等，等的是黑五可能上架的新配置档位，而不是现有套餐再降一轮。
